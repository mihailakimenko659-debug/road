# Солнечная система — интерактивная 3D-модель

Обучающая 3D-модель Солнечной системы на [three.js](https://threejs.org/). Всё работает в браузере, без сборки.

## Запуск

Модули ES не открываются через `file://`, поэтому нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или включите GitHub Pages для ветки — `index.html` лежит в корне.

## Что можно делать

- **Двигать и изучать**: вращение мышью, колесо — приближение, правая кнопка — сдвиг, клик по планете или подписи — перелёт к ней. Клавиши `0`–`8` (Солнце и планеты), `пробел` — пауза, `Esc` — обзор.
- **Время**: скорость от минут до лет в секунду, обратный ход, кнопка «Сегодня». Начальные положения планет соответствуют текущей дате.
- **Масштаб**: наглядный, реальные расстояния, полностью реальный (с настоящими размерами планет).
- **Слои**: орбиты, подписи, спутники, оси вращения, пояс астероидов, обитаемая зона.
- **Лаборатория «Что если?»** для каждой планеты: расстояние до Солнца, эксцентриситет, масса, радиус, наклон оси, период вращения, альбедо. Пересчитываются длина года (3-й закон Кеплера), солнечные сутки, сила тяжести, вторая космическая скорость, плотность, освещённость, температура, времена года и ваш вес на планете.
- **Масса Солнца**: меняет светимость, все периоды обращения и границы обитаемой зоны.
- **Готовые опыты**: Земля на орбите Венеры/Марса, вытянутая орбита, Земля без наклона оси, Юпитер в 80 раз тяжелее, более массивное Солнце.

## Структура

- `index.html`, `css/style.css` — интерфейс
- `js/data.js` — данные планет и спутников (NASA Planetary Fact Sheet)
- `js/physics.js` — формулы
- `js/textures.js` — процедурные текстуры планет (рисуются на canvas)
- `js/main.js` — сцена, анимация, управление
- `vendor/` — three.js r160 (MIT)
