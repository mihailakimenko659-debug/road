# Огниво — интро «роза из искр»

Демо-переход: искры слетаются в розу, роза взрывается огненным шаром, страница тлеет снизу,
загорается, резко вспыхивает и сгорает, открывая основной сайт.

- `app.js` — роза из искр, горящая страница, угольки, временная шкала
- `fluid.js` — симуляция горячего газа на видеокарте (температура, дым, вихри, давление)
- `post.js` — HDR-свечение с сохранением прозрачности
- `vendor/` — three.js r160 (MIT)

Отладка: `?t=4.5` в адресе замораживает интро на нужной секунде.
