# Ладно — линейка прототипов

Кликабельные прототипы приложений из исследования `reports/Семейная мотивация и единые сервисы.md`. В основе у всех одна механика:

**участники → задачи → подтверждение → баллы или вклад → договор → история → награды**

Её можно сделать один раз и использовать в разных шаблонах, а не писать пять отдельных приложений. Это главный вывод исследования.

| Файл | Прототип | Для кого | Вывод исследования |
|---|---|---|---|
| `family.html` | Семья | родители и дети: задания, баллы, торг, мечта | делать первым |
| `team.html` | Кафе | небольшая команда: чек-листы смен, «спасибо», прозрачная премия вместо штрафов | второй шаг: бизнес платит охотнее |
| `pair.html` | Вдвоём | пара или соседи: честное деление дел с учётом «веса» и невидимой работы | легко сделать на том же ядре |
| `care.html` | Забота | братья и сёстры вместе заботятся о пожилом родителе; экран мамы с большими кнопками | сильная боль, узкая честная версия «всё в одном» |
| `teen.html` | Подработка | подросток зарабатывает у родных и соседей, которых пригласил родитель | только доверенный круг, деньги мимо приложения |

`index.html` — главная страница со всеми прототипами, цифрами спроса и порядком проверки.

В каждом прототипе есть:
- переключатель «Смотреть как» (одна ситуация глазами разных людей);
- экран «Решения»: какие проблемы нашло исследование (с источниками и датами) и как прототип их решает;
- раздел «Что нужно для настоящего продукта»;
- пример данных, который можно вернуть к началу.

Данные хранятся только в браузере, на этом устройстве. Синхронизация между телефонами — задача полноценного приложения.

Запуск локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/ladno/
```

## Что нужно для настоящего приложения (общее для всех шаблонов)

1. **Синхронизация между телефонами.** Вход по номеру телефона, для детей — по коду от родителя.
2. **Серверы в России** (Yandex Cloud или VK Cloud), уведомление Роскомнадзора, отдельное согласие на обработку данных.
3. **Платформы по шагам.** Сначала веб-приложение и бот в MAX/Telegram для напоминаний, затем Android в RuStore. iPhone работает через веб-версию.
4. **Надёжность.** Работа без интернета и резервная копия.
5. **Деньги.** Без рекламы в детской части. Оплата через сайт (ЮKassa, СБП). Цены — гипотезы, их нужно проверить.
6. **Стоимость первой версии** у небольшой студии — 260–600 тыс. ₽ (оценки студий, 2026).

## Порядок проверки

1. **Семья:** 10–20 семей на месяц. Успех — через 4 недели больше половины семей всё ещё отмечают задания.
2. **Кафе:** 3–5 заведений. Смотрим, меньше ли споров о премии и выполняются ли чек-листы.
3. **Вдвоём:** шаблон того же ядра.
4. **Забота и Подработка:** после, потому что у них больше юридических вопросов.
