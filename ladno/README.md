# Ладно — семейный договор (прототип)

Кликабельный прототип семейного приложения: родители ставят задания, дети зарабатывают баллы, торгуются о цене, копят на большую мечту вместе с родственниками и меняют баллы на награды. Правила записаны в договоре, который подписывают все.

Прототип — одна веб-страница (`index.html`) без сервера. В ней пример семьи: папа, Миша (12 лет, копит на игровой компьютер) и Аня (8 лет, копит на велосипед). Вверху можно переключаться между ними и смотреть на одну семью глазами разных людей. Данные хранятся только в браузере, на этом устройстве.

Запуск локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/family/
```

Основа — исследование `reports/Семейная мотивация и единые сервисы.md`.

## Что нужно для настоящего приложения

Прототип показывает механику. Для настоящего приложения нужно:

1. **Синхронизация между телефонами.** Родитель входит по номеру телефона, ребёнок — по коду от родителя, без своей почты. Изменения видны всем сразу.
2. **Серверы в России** (Yandex Cloud или VK Cloud). Нужны уведомление Роскомнадзора и отдельное согласие родителя на обработку данных ребёнка.
3. **Платформы по шагам:** веб-приложение, которое ставится на экран телефона (работает и на iPhone, и на Android), плюс бот в MAX и Telegram для напоминаний. Затем Android-приложение в RuStore. Пуш-уведомления через RuStore Universal Push.
4. **Уведомления:** «задание ждёт проверки», «папа ответил на твою цену», «до мечты осталось 10%», итог недели по воскресеньям.
5. **Надёжность:** работа без интернета, резервная копия, восстановление семьи на новом телефоне.
6. **Деньги:** без рекламы в детской части. Бесплатная основа и семейный тариф через сайт (ЮKassa, СБП). Цена 149–299 ₽ в месяц — гипотеза, её нужно проверить.
7. **Стоимость:** первая версия у небольшой студии — 260–600 тыс. ₽ (оценки студий, 2026).

## Как проверить идею до разработки

Дать прототип 10–20 семьям на месяц и смотреть:

- через 4 недели больше половины семей всё ещё отмечают задания;
- дети сами предлагают задания хотя бы раз в неделю;
- родители проверяют задания в тот же день;
- хотя бы в каждой третьей семье родственники делают взнос в мечту.

Если семьи бросают через пару недель, ту же основу (задания, баллы, договор, прозрачная история) можно перенести в небольшие кафе. Там вместо штрафов — законное снижение премии по положению о премировании.
