# SHOV — анимация молнии при прокрутке

Демо для сайта бренда одежды. Пока страница прокручивается, экран стоит на месте:
по центру расстёгивается металлическая молния, ткань расходится и заворачивается
отворотами, показывая стёганую подкладку, затем обложка уходит вдаль, а вещи
коллекции прилетают с разных сторон и садятся на свои места.

- `index.html` — разметка и стили
- `app.js` — 3D-ткань (three.js), молния, бегунок, полёт карточек
- `products.js` — рисунки вещей и данные карточек (замените на фото товаров)
- `vendor/` — three.js r160 (MIT)

Запуск: `python3 -m http.server` в корне репозитория и открыть `/zipper/`.
